# Project Exodus

Minecraft 1.21.1 / NeoForge Create: Cosmonautics survival modpack and compatibility addon.

**[Download entire modpack via GitHub Actions](https://github.com/StarTraveler24/Exodus---Minecraft/actions/workflows/package-modpack.yml)**

Open a successful packaging run → Artifacts → Project-Exodus-CurseForge-Import, then extract and import its ZIP into CurseForge.

**Setup still needed:** Place the full CurseForge export at `modpack/Project-Exodus-Profile.zip` in this repository. The initial source-only ZIP does not contain the full modpack. Once committed, the packaging workflow will create a downloadable complete import ZIP automatically.
